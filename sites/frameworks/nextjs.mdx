A Next.js app built as a [static export](https://nextjs.org/docs/app/guides/static-exports) is a site. An app that uses server rendering, server actions, API route handlers or middleware needs a server: make it a [Mist app](/mist-apps/overview) instead. See [Site or App?](/sites/site-or-app).

## Configure the export

```js next.config.mjs
export default {
  output: "export",
  trailingSlash: true,
  images: { unoptimized: true },
};
```

- `output: "export"` writes plain files to `out`.
- `trailingSlash: true` writes each page as `about/index.html`, which the site serves at `/about`.
- `images.unoptimized` is needed because there is no image server.

## Use the SDK

The SDK runs in the browser. Use it in a client component:

```tsx app/hello.tsx
"use client";
import { useEffect, useState } from "react";
import { fluid } from "@fluid-app/sites";

export function Hello() {
  const [name, setName] = useState<string | null>(null);
  useEffect(() => {
    fluid.auth.me().then((me) => setName(me.viewer?.name ?? null));
  }, []);
  return <p>{name ? `Hi, ${name}` : "Hi there"}</p>;
}
```

## Deploy

```bash
fluid deploy
```

`fluid deploy` sees `output: "export"` and publishes `out`. To publish an export by hand, run `fluid sites publish --dir out`.
