A folder of HTML files is a site. There's nothing to install and no build step: `npx create-fluid-site my-page --template html` starts one.

## Load the SDK

Every published site serves the SDK at `/_fluid/sdk/v1/sites.js`. Import it in a module script:

```html index.html
<p id="hello">Hi there</p>
<script type="module">
  import { fluid } from "/_fluid/sdk/v1/sites.js";

  const me = await fluid.auth.me();
  if (me.viewer) document.querySelector("#hello").textContent = `Hi, ${me.viewer.name}`;
</script>
```

<Note>
  `fluid sites dev` doesn't serve `/_fluid/sdk/v1/sites.js` yet, so the import fails locally. Try the page on the published site, or install `@fluid-app/sites` and use a bundler.
</Note>

## Pages

Put each page in the folder: `/about` is answered by `about.html` only if you add a route, or by `about/index.html` with no configuration. See [Routes](/member-sites-v1/declarations#routes).

## Deploy

```bash
fluid deploy
```

`fluid deploy` sees a folder of HTML with no build and publishes it as it is.
