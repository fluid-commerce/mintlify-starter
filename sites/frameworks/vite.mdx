Vite projects work as they are. `npm create @fluid-app/fluid-site my-site` starts you on Vite and React; an existing Vite project needs only the SDK.

## Set up

```bash
npm install @fluid-app/sites
```

Import it once, at the top of your entry file:

```ts src/main.tsx
import { fluid } from "@fluid-app/sites";

const me = await fluid.auth.me();
```

Keep Vite's default `base` of `/` and its default build folder, `dist`.

## Routing

With no `config/routes.json`, every path that isn't a file is answered by `index.html`, which is what a client-side router needs. Inside the storefront, let your router follow Back and Forward:

```ts
fluid.history.onGo((path, hash) => router.navigate(path + (hash ?? "")));
```

See [Routes](/member-sites-v1/declarations#routes) to send some paths to other files.

## Deploy

```bash
fluid deploy
```

Run [`fluid sites dev`](/sites/local-development) instead of `npm run dev` to get a working `fluid.db` while you build.
