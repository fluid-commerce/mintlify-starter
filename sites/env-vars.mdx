A site can hold named values for its [functions](/sites/functions): an API key for another service, a webhook signing secret, a feature switch. Set them once and every function reads them.

## Set a value

```bash
fluid sites env set NEWSLETTER_LIST_ID 8f2c1a
fluid sites env set STRIPE_SECRET_KEY sk_live_51Hx... --secret
fluid sites env list
fluid sites env unset NEWSLETTER_LIST_ID
```

- A **secret** can be set and removed, but never read back: `fluid sites env list` shows its name only. Use it for keys and passwords.
- A plain value can be read back by anyone who manages the site.

## Names

A name is capital letters, digits and underscores, starts with a letter, and is at most 64 characters, such as `NEWSLETTER_LIST_ID`. Names that start with `FLUID_` are reserved. A site holds at most 64 values.

## Use them

Functions receive them as `ctx.secrets`:

```ts functions/subscribe.ts
export default async (request: Request, ctx) => {
  const key = ctx.secrets.STRIPE_SECRET_KEY;
  // ...
};
```

Values never reach the browser. A page that needs one calls a function that uses it.

## Through the API

`GET`, `PUT` and `DELETE` on `/api/member/v2026-10/sites/{site_id}/env_vars`, or `/api/company/v2026-10/member-sites/{id}/env_vars` as an admin.
