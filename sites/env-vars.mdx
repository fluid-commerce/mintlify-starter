A site can hold named values for its [server functions](/sites/functions): an API key for another service, a webhook signing secret, a feature switch. Set them once and every function of the site receives them.

## Set a value

```bash
fluid sites env set NEWSLETTER_LIST_ID 8f2c1a
fluid sites env set STRIPE_SECRET_KEY --secret --stdin < stripe-key.txt
fluid sites env set NEWSLETTER_LIST_ID 8f2c1a --folder ./my-event
fluid sites env list
fluid sites env unset NEWSLETTER_LIST_ID --yes
```

- `--stdin` reads the value from standard input, so a secret never appears in your shell history.
- `unset` asks before it removes a value. `--yes` skips the question, for example in CI.
- A **secret** can be set and removed, but never read back: `fluid sites env list` shows its name only. Use it for keys and passwords.
- A plain value can be read back by anyone who can publish the site.
- `--folder` names the site's folder when you're not in it. The other `env` commands take the folder as their last argument.

## Names

A name is capital letters, digits and underscores, starts with a letter, and is at most 64 characters, such as `NEWSLETTER_LIST_ID`. Names that start with `FLUID_` are reserved. A value is at most 5 KB, and a site holds at most 64 values.

## Use them

A function reads every value, secret or not, by name from `ctx.secrets`. There's no `process.env`:

```ts functions/subscribe.ts
export default async function (request: Request, ctx: any): Promise<Response> {
  const { email } = await request.json();
  const res = await fetch(`https://api.newsletter.example.com/lists/${ctx.secrets.NEWSLETTER_LIST_ID}/members`, {
    method: "POST",
    headers: { Authorization: `Bearer ${ctx.secrets.NEWSLETTER_API_KEY}`, "Content-Type": "application/json" },
    body: JSON.stringify({ email }),
  });
  return new Response(null, { status: res.ok ? 204 : 502 });
}
```

- A set or an unset reaches the site's published functions at once. You don't need to publish again.
- If the CLI says a value was saved but didn't reach the functions, run the same command again.
- No value is ever sent to the browser, so a page can't read one. Don't put a secret in the site's build: everything in it is public.
