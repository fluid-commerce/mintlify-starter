**You can connect an AI agent to Fluid in three ways.** Pick by what the agent needs to do:

| Option | What the agent can do | Credentials |
| --- | --- | --- |
| [Docs MCP server](#docs-mcp-server) | Search and read the Fluid docs and API specs | None |
| [Fluid CLI](#fluid-cli) | Make changes to your company: themes, guided setups, and more | Your sign-in, or an API token |
| [Mist](#mist) | Build and change things for your company by chatting | Your Fluid sign-in |

Most agents use the first two together: the docs MCP server to look up how something works, and the CLI to do it.

## Docs MCP server

Fluid's docs come with a hosted, read-only [Model Context Protocol](https://modelcontextprotocol.io) (MCP) server at:

```text
https://docs.fluid.app/mcp
```

There's nothing to install, and it needs no API token. Connected agents can:

- **Search** the docs, guides, and API reference.
- **Read** any docs page or OpenAPI spec in full.
- **Send feedback** about a docs page that's wrong or missing something.

It only reads published documentation. It can't read or change your company's data, and it doesn't accept an API key.

### Connect from a docs page

Every docs page has a menu at the top. Use it to copy the MCP server URL or install the server in Cursor or VS Code in one click.

### Connect by hand

<Tabs>
  <Tab title="Claude Code">
    Run this in any terminal. Claude Code keeps the server in your configuration.

    ```bash
    claude mcp add --transport http fluid-docs https://docs.fluid.app/mcp
    ```
  </Tab>
  <Tab title="Cursor">
    Add this to `~/.cursor/mcp.json` for every project, or `.cursor/mcp.json` for one project. Then restart Cursor.

    ```json
    {
      "mcpServers": {
        "fluid-docs": {
          "url": "https://docs.fluid.app/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="VS Code">
    VS Code needs the transport type. Add this to `.vscode/mcp.json` in your project, or run **MCP: Open User Configuration** from the Command Palette to add it for every project.

    ```json
    {
      "servers": {
        "fluid-docs": {
          "type": "http",
          "url": "https://docs.fluid.app/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="Claude Desktop">
    Add remote servers in the app, not in `claude_desktop_config.json`. Go to **Settings** → **Connectors** → **Add custom connector**, and paste `https://docs.fluid.app/mcp`.
  </Tab>
</Tabs>

The same setup steps are in the admin, on **Settings** → **Developer**. See [Developer](/help/admin/settings/developer).

### Without MCP

Agents that can't use MCP can still read the docs:

- [`/llms.txt`](https://docs.fluid.app/llms.txt) indexes every page for language models.
- [`/skill.md`](https://docs.fluid.app/skill.md) is a short guide for AI tools: where to look, Fluid's naming, and the main conventions.
- Every page can be copied as Markdown from its page menu.

## Fluid CLI

To make changes, give the agent the [Fluid CLI](/themes/cli). It works on your company's themes, and its plugins run Fluid's [guided setups](/setup/overview), such as connecting a back office, opening a country, or setting up payments onboarding. Every guided-setup command prints JSON, so an agent can read the result of each step.

Sign the CLI in one of two ways:

- **Your own sign-in.** Run `fluid login` and enter the code Fluid emails you. Use this when you're at the keyboard with the agent.
- **An API token.** Create one at **Settings** → **API Tokens**, then sign in with it. Pass it in an environment variable so it stays out of your shell history:

  ```bash
  FLUID_TOKEN=<your_token> fluid login
  ```

  Use this when the agent runs on its own. See [Authentication](/api/authentication) for token types.

Run `fluid theme skills install` to give your agent Fluid's theme skills as well. To set up a whole store with an agent, follow the [agent launch guide](/api/agent-launch).

The docs MCP server and the CLI are separate. The MCP server never sees your token.

## Mist

[Mist](/help/mist) is Fluid's own AI assistant, a desktop app that builds and changes things for your company when you chat with it. You sign in with your Fluid account, so it doesn't need an API token or an MCP setup.

The [Mist Skills](/guides/mist-skills) repository has the skills and workflows Mist uses. Many of them also work in other agents, such as Claude Code, outside Mist.
