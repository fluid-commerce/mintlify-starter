A theme widget is a reusable, theme-owned Liquid template with its associated assets, helper templates, and translations. Theme widgets are distinct from [Droplet theme extensions](/themes/droplet-theme-extensions) and [portal widgets](/portal-widgets/overview).

## Before you start

Sign in to Mist and open the theme project you want to work on. Use a theme project for this workflow, rather than a portal widget project.

To import a shared widget, you need a signed-in Fluid account with permission to view and update themes in the destination company.

## Create a widget

You can also ask Mist in the theme's chat: **Create a theme widget named Member card.**

1. Open **Widgets** in the theme editor.
2. Enter a **Widget name**, such as **Member card**.
3. Click **Create widget**. Mist creates a local starter widget with a heading setting.
4. Ask Mist to customize the widget in the theme's chat. For example:

   > Customize the Member card theme widget with a heading, a short message, and a link. Keep its styles with the widget and make the layout work on small screens.

Creation stays local. It does not publish the theme or add the widget to a page.

Start names with a letter and use letters, numbers, spaces, hyphens, or underscores. If a widget with that name already exists locally, choose a different name; creation does not overwrite it.

Mist converts names to lowercase and replaces spaces and hyphens with underscores. The resulting name must be at most 64 characters. For example, **Member card** and **member-card** both use the same local name.

## Keep the widget portable

Keep the assets and helper templates that the widget needs with its theme files. Use explicit template and asset references so sharing can identify its dependencies.

Sharing includes widget-owned files and supported literal resource references, including Liquid asset filters, HTML resource attributes, and CSS resource URLs. A filename mentioned only in a caption is not an asset dependency.

### Declare assets used by JavaScript

Declare each JavaScript-linked file with a literal Liquid `asset_url` reference in the rendered widget template, such as `index.liquid`. Pass the rendered URL to JavaScript through a data attribute or an inline Liquid URL:

```liquid
<div id="member-card" data-details-url="{{ 'member-card.json' | asset_url }}"></div>
<script>
  const detailsUrl = document.querySelector('#member-card').dataset.detailsUrl;
  fetch(detailsUrl);
</script>
```

A filename in a raw `.js` or `.mjs` string or comment does not declare an asset. Sharing does not infer dependencies from runtime `fetch`, `require`, `URL`, `Worker`, or DOM filename usage. If sharing reports a local runtime filename, declare its URL in Liquid and pass that URL to the script, even when the file is already included for another reason.

Literal relative module `import` and `export` declarations are followed automatically. Bare package imports do not declare theme assets. Liquid, HTML, CSS, and typed resource JSON references remain supported, and associated widget-owned and native files remain included.

Literal translation keys used with the Liquid `t` filter travel with the widget. Sharing refuses keys built from variables or passed through another filter before `t`. If you see **Use literal translation keys to share this widget**, replace those expressions with literal keys before generating a link. Unrelated theme translations are excluded.

A share supports up to 256 files, with a maximum of 2 MiB per file and 10 MiB total. Reduce large assets if the bundle exceeds these limits.

Save your edits before sharing. Mist captures the current local files when you generate the link, including changes you have not published to the theme.

## Copy a share link from Mist

1. In Mist, open **Widgets** and find your widget under **Theme widgets**.
2. Click **Share widget** to generate a link and open the sharing dialog.
3. Click **Copy link**. Mist copies the URL to your clipboard and shows **Link copied**.
4. Send the copied link to the recipient.

If clipboard access fails, select and copy the URL shown in **Share link**.

Existing share links remain supported.

The link contains a snapshot. Later edits do not change it; generate a new link to share an updated version. Generating or copying a link does not publish your theme.

<Warning>
  Anyone with the link who signs in and can edit a destination theme can import the snapshot, including someone in another company. Share only widget code, assets, and text you intend to make available to those recipients.
</Warning>

## Clone a shared widget into a theme

1. Open the shared link in your browser and sign in to Fluid if prompted.
2. In **Import shared widget**, choose a **Destination theme** in your current company. Use **Load more themes** if your theme is not listed yet.
3. Click **Import widget**.
4. After the confirmation appears, click **Open theme** to continue working with the copy.

Opening the link does not import anything until you choose a theme and click **Import widget**.

The destination receives its own widget, associated assets, helper templates, and referenced translations. The import uses fresh ownership and avoids replacing an existing widget with the same name.

The copy does not grant access to the source company. Later source edits do not update your imported copy.

Importing does not add the widget to pages or activate the destination theme. Review the copy before placing it in a page or publishing your theme changes.

## Troubleshooting

- **Widgets is missing:** Confirm you opened a theme project and that this workflow is available for your company.
- **A new local widget is missing from the list:** Click **Refresh** in **Widgets**.
- **No editable themes are available:** Check your current company and theme permissions. Development branches are not import destinations.
- **The link is unavailable:** Ask the sender for a new link. Revoked links cannot be imported.
- **Sharing fails:** Check that the widget files exist and the configuration and schema contain valid JSON. Droplet installation references cannot be shared as theme widgets.
