The Page Editor is where merchants arrange sections and blocks on a theme template and change their settings.
Everything they see in it comes from your theme's code.
This page maps each part of the editor to the code that drives it.

For a screen-by-screen guide to the editor, see [Page Editor](/help/admin/page-editor) in the Help Center.

## How a page is built

```text
Template
└── Sections
    └── Blocks
```

A template, such as `product/default`, holds an ordered list of sections.
A section can hold blocks.
Merchants edit one template at a time.

## What each panel reads

| Panel | What it shows | Driven by |
| --- | --- | --- |
| **Templates** | The theme's templates, in **Storefront** and **CMS** folders by page type | The template directories, such as `product/default/` |
| **Layers** | The sections and blocks on the current template | The template's sections and each section's blocks |
| **Sections** | Sections a merchant can drag onto the template | `sections/`, filtered by `enabled_on` |
| **Theme** | Theme-wide settings | `config/settings_schema.json`. See [settings schema](/themes/settings-schema) |
| **Widgets** | Widgets and sections from installed droplets | See [Droplet theme extensions](/themes/droplet-theme-extensions) |
| Settings panel, on the right | The selected section's or block's settings | The schema's `settings`. See [schema components](/themes/schema-components) |

The rail also has **Site Menu**, where merchants edit navigation menus, navigation bars, and footers.

## Make sections available

The **Sections** panel lists a section under **Drag to add** when its schema allows the current template, and under **Not available here** when it doesn't.
A section without `enabled_on` is available on every template.

```json
{
  "name": "Product highlights",
  "enabled_on": {
    "templates": ["product"]
  }
}
```

<Note>
  The editor does not read `disabled_on`.
  To keep a section off a template, list the templates it belongs on in `enabled_on`.
</Note>

## Make sections and blocks selectable

Fluid wraps each section in an element that the editor uses to select it, so a section needs no extra markup.
Add `{{ block.fluid_attributes }}` to each block's outer element.
Without it, merchants can't select the block in the preview.
See [blocks and components](/themes/blocks-and-components#make-blocks-selectable-in-the-page-editor).

## Shape the settings panel

The settings panel renders a section's or block's `settings` in order:

- A `header` setting starts a collapsible group.
- `visible_if` shows a setting only when its condition is true.
- `info` adds help text below a control.

See [schema components](/themes/schema-components) for every setting type and what it saves.

## Edit code in the editor

**Code** in the top bar switches the template to code editing.
Its tabs hold the template's Liquid, its CSS when the template has its own stylesheet, and its variables as JSON.
A section opened from the **Sections** panel always opens in code mode.

For larger changes, work locally with the [Fluid CLI](/themes/cli) and preview them with `fluid theme dev`.

## Save and publish

Most edits stay in the editor until the merchant clicks **Save**.
The editor's **X** button closes it without asking about unsaved changes, so save first.
A saved template goes live only after **Publish**.

<Warning>
  Saving in the **Template Translations** sheet publishes right away, including any other unsaved or unpublished changes on the template.
  See [Translate a template](/help/admin/page-editor#translate-a-template).
</Warning>
