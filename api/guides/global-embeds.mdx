---
title: "Manage global embeds"
description: "Add and review privileged HTML or scripts for storefront and checkout pages."
---

Global embeds let authorized admins add privileged HTML or scripts to storefront or checkout pages.

## Create and review an embed

1. Create the embed as a draft in Fluid Admin.
2. Choose whether it targets the storefront or checkout.
3. Place the content in the page head or body.
4. Review and test the content before you make it active.

Draft embeds do not run on the selected target. Active embeds do.

## Protect buyer-facing pages

Embed content can execute on buyer-facing pages. Limit edit access, review every third-party script and destination, and confirm what data the content collects before activation.

Keep a reviewed copy of the previous content so you can restore it if the embed disrupts a page.

## Integration boundary

There is no generated Global Embeds endpoint reference. Manage global embeds in Fluid Admin, and do not present the management surface as a supported external integration contract.
