---
title: "Droplet Widget Package quickstart"
description: "Create a standalone widget project, link it to an existing Droplet, and publish a version."
---

A standalone Widget Package belongs to an existing Droplet and publishes widget code and metadata for that Droplet.

The generated project uses [`defineWidgetPackage`](/portal-widgets/reference/widget-worker-sdk/functions/defineWidgetPackage) and [`startWidgetPackage`](/portal-widgets/reference/widget-worker-sdk/functions/startWidgetPackage) from the supported worker SDK.

## Create the project

```bash
fluid widget create reviews-package
cd reviews-package
pnpm install
```

You can link an existing Droplet during creation:

```bash
fluid widget create reviews-package --droplet <droplet-id>
```

## Link the Droplet

If the project is not linked yet:

```bash
pnpm run widget:link
```

The command writes the selected Droplet ID to `fluid.widget.config.ts`. It does not change the package identity, version, or widget registrations in `manifest.ts`.

## Start development

```bash
pnpm dev
```

The development server normally runs at `http://localhost:5174`. Preview the package through a portal or builder. The command does not start a separate preview application.

## Validate and build

```bash
pnpm typecheck
pnpm validate
pnpm build
pnpm run widget:publish --dry-run
```

Render the built package through a portal or builder. A successful build cannot verify appearance, accessibility, or theme behavior.

## Publish

Increment the semantic `version` in `manifest.ts`, then run:

```bash
pnpm run widget:publish
pnpm exec fluid widget status
pnpm exec fluid widget logs
```

Publication creates an immutable Droplet widget version. Use a new version for every published change.
