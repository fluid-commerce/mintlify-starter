## Frequently asked questions

<AccordionGroup>
  <Accordion title="How do I access and navigate the Learning feature?" id="how-do-i-access-and-navigate-the-learning-feature">
    Your company's trainings are in the mobile app. Where you find them depends on how your company sets up the app. For example, a **Get Started** widget on the Home screen shows trainings from a category your company chooses. If your company groups its trainings into categories, you can browse them by category.

    Training videos remember where you stopped, so you can leave and pick up where you left off.

    Brand teams add trainings on the admin's [Trainings](/help/admin/trainings) screen, under **Tools**, and choose where they appear in the app with [Home Tabs](/help/admin/mobile/home).
  </Accordion>
  <Accordion title="What are the key elements of an effective AI prompt?" id="what-are-the-key-elements-of-an-effective-ai-prompt">
    When you ask an AI assistant to draft a reply to a customer, give it three things:

    | Part | What to include | Example |
    | - | - | - |
    | Context | The issue, the customer's own words, technical details and account status | "Customer reports a sign-in error in the mobile app, version 2.1. Loyal customer for two years." |
    | Desired outcome | The tone, what the answer must cover, and what happens next | "A friendly, step-by-step answer, with a way to check it worked and a reminder about account security." |
    | Special instructions | Brand voice, technical level, required elements and regional details | "Use our brand voice. Keep it simple. Include mobile-specific steps." |

    **Templates for common requests**

    | Situation | Prompt structure | Example |
    | - | - | - |
    | Technical issue | Issue, technical context, what you need | "Issue: can't open the dashboard. Context: iOS 18, app version 2.1. Need: basic troubleshooting steps." |
    | Feature question | Feature, customer's experience level, focus | "Feature: analytics. Level: beginner. Focus: reading the weekly summary." |
    | Billing question | Account status, the problem, the resolution you need | "Account: active subscription. Problem: charged twice. Need: how a refund works." |

    **Make the reply fit**

    - **Technical level:** simple steps for beginners, more detail for advanced users.
    - **Tone:** say whether you want it friendly ("Happy to help!") or formal ("I'll help you with this").
    - **Required elements:** for example, a security reminder or a link to more information.

    Always include the platform and version, the account type, what's already been tried, and what a good answer looks like. Mention error messages, the customer's language and any time pressure. Review every draft before you send it.
  </Accordion>
  <Accordion title="What are the essential steps for creating an effective course?" id="what-are-the-essential-steps-for-creating-an-effective">
    Brand teams add trainings on the admin's [Trainings](/help/admin/trainings) screen, under **Tools**. Plan each course before you build it.

    **Course checklist**

    | Phase | What you need | Best practices | How to measure it |
    | - | - | - | - |
    | Planning | Learning goals, an outline, time estimates and a target audience | A clear progression, logical breaks, the right skill level | Completion, what people learn, time taken |
    | Creating content | Videos, documents and supporting materials | Videos of 10 minutes or less, short segments, real-world examples | Engagement and feedback |
    | Setting up | A clear title, the right category, and where it appears in the app | Consistent formatting, accessibility, works on phones | Whether people find and finish it |

    **Content guidelines**

    | Content type | Key elements | Production tips |
    | - | - | - |
    | Video lessons | Clear audio, good visuals, an engaging pace | Good equipment, captions, chapters |
    | Written materials | Structured content, visual aids, practice exercises | Templates, graphics, consistency |
    | Interactive elements | Discussion questions, case studies, practical exercises | Vary the questions, use real scenarios, give feedback |

    **Course structure**

    | Section | Purpose | What it includes |
    | - | - | - |
    | Introduction | Overview | Learning goals, prerequisites, time needed |
    | Core content | The main material | Video lessons, reading, practice |
    | Check | Confirm what people learned | Questions and practical tasks, in a live session or a follow-up |
    | Resources | Further support | Reference materials, tools and templates |

    Start with a detailed outline, build in short modules, and offer downloadable resources. Fluid's trainings don't include quizzes, so check understanding in a live session or a follow-up.
  </Accordion>
</AccordionGroup>
