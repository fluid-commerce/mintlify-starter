Mist can use AI models from several providers. Each chat has its own model, which you choose from the model picker in the chat box. **Auto** is the default, and it picks a model for you on every message.

## Choose a model for a chat

<Steps>
  <Step title="Open the model picker">
    In the chat box, click the model name.
  </Step>
  <Step title="Find a model">
    Models are grouped by provider, such as **OpenAI** or **xAI**. Type in **Search models…** to filter the list. Each model shows its context size and its price per million output tokens.
  </Step>
  <Step title="Pick it">
    Click the model. The chat uses it from your next message.
  </Step>
</Steps>

To go back to automatic choice, pick **Auto**, under **Default**.

## How Auto works

Before each message, **Auto** asks a small, fast model which of three tiers the message needs. It's told to pick the cheapest tier that will still do the job well.

| Tier | Used for | Model |
| --- | --- | --- |
| Quick | Conversation, short answers, a single lookup or a one-line change | GPT-6 Luna |
| Standard | Everyday work, such as editing a few files, a data query with some analysis, or drafting content | Claude Sonnet 5.5 |
| Complex | Building a feature, theme, page, portal or app, debugging an unclear failure, planning, or several tasks at once | Claude Opus 5.5 |

**Auto** also follows these rules:

- If it isn't confident about a tier, it moves up one tier.
- A message with several tasks, or with text files attached, uses at least the standard tier.
- A message that's likely to change production, such as publishing, deploying, writing through the Fluid API, issuing a refund, writing to a database or deleting something, uses the complex tier.
- In a long chat that was active in the last 5 minutes, it doesn't drop to a cheaper model than the one it used last. There, a cheaper model would cost more, because it can't reuse the chat the current model has already cached.
- If it can't choose within about 2.5 seconds, or the choice fails, it uses Claude Opus 5.5.

So **Auto** saves cost on simple messages, and uses the most capable model where a mistake would matter most.

## Set the default model for new chats

<Steps>
  <Step title="Open Preferences">
    Click your name at the bottom of the sidebar, then click **Preferences**.
  </Step>
  <Step title="Choose the default">
    Under **Default chat model**, pick a model, or **Auto — Mist recommended**.
  </Step>
</Steps>

New chats on this computer use this model. Chats you already have keep their own model.

If you haven't set a default, a new chat uses the model you picked most recently, or **Auto**.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does the model I choose change the cost?" id="cost">
    Yes. Each model has its own price, which the picker shows. Your company pays for Mist's AI usage, up to a daily cap. See your company's usage under **Settings** > **AI usage** in Mist, or on [AI Spend](/help/admin/settings/ai-spend) in the admin.
  </Accordion>
  <Accordion title="Why did my chat switch back to Auto?" id="switched-to-auto">
    The model you picked is no longer available. Mist moves the chat to **Auto** when that happens.
  </Accordion>
  <Accordion title="What happens when my company runs out of AI credits?" id="out-of-credits">
    Mist stops answering and tells you why, for example "Your company is out of AI credits." or "Your company's AI spend limit is reached." An admin can check [Billing](/help/admin/settings/billing) in the admin.
  </Accordion>
</AccordionGroup>
