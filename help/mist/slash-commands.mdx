Type **/** at the start of the chat box to open the command menu. The menu lists commands first, then your skills, then your workflows. Keep typing to filter it.

## Commands

| Command | What it does |
| --- | --- |
| `/ask` | Ask a question about your code without changing it. Mist reads the files it needs and makes no edits. |
| `/clear` | Clear the chat history. Mist asks you to confirm, because this can't be undone. |
| `/compact` | Ask Mist to summarize the conversation so far, so you can carry it into a new chat. |
| `/files` | Show the project's file structure. |
| `/run` | Run a shell command in the project. Type the command after `Run:`. |
| `/explain` | Explain a file or a recent change. Type what to explain after `Explain`. |
| `/screenshot` | Take a screenshot of the preview and describe it. Mist starts the preview first if it isn't running. |
| `/rip` | Save a video from a link into your DAM and Media library. Paste the video link after the command. |
| `/dashboard` | Build a live dashboard of your business from your company's data. |
| `/help` | Close the menu. The command menu itself is the list of commands. |

Except for `/clear` and `/help`, a command puts a ready-made request in the chat box. Add to it or change it, then press Enter to send it.

## Run a skill or workflow

The same menu lists your skills, marked **Skill**, and your workflows, marked **Workflow**.

- Pick a skill to add it to your message, then send the message. See [Skills](/help/mist/skills).
- Pick a workflow to start it right away. See [Workflows](/help/mist/workflows).

<Warning>
  Picking a workflow starts the run as soon as you select it. Workflows can make changes to your company. Turn on [Safe Mode](/help/mist/safe-mode) first if you only want to explore.
</Warning>

## Mention context with @

Type **@** in the chat box to add context to your message, such as a file in your project or another project in your workspace. Pick a kind of item, then the item. Keep typing after **@** to search.
