Instead of describing where something is on the page, you can pick it. Mist then knows exactly which element you mean.

## Before you start

- Run the project, so its preview is running on your computer. See [Run and publish](/help/mist/run-and-publish).
- The element picker isn't available on widget previews.

## Pick an element

<Steps>
  <Step title="Turn on the picker">
    In the preview toolbar, click the pointer button, **Pick element from preview**.
  </Step>
  <Step title="Click the element">
    The preview shows **Click an element to pin it · Esc to cancel**. Click the element you mean.
  </Step>
  <Step title="Tell Mist what to change">
    The element appears as a chip in the chat box. Type what you want, such as "Make this button match the brand color", then send it.
  </Step>
</Steps>

To cancel without picking, press Esc. To drop a picked element before you send, click **Remove element** on its chip.

## What Mist receives

When you send, Mist gets:

- The element's HTML, up to 4 KB.
- The address of the page in the preview.
- For apps built with React, the source file and line that render the element.

For a theme, Mist doesn't get a source file. It also selects the matching section in the section editor.
