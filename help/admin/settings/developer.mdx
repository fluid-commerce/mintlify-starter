The **Developer** screen collects the resources you need to build on Fluid. It links to the documentation and your developer settings, shows how to set up developer tools, and gives you the Fluid SDK snippet for your website.

## Where to find it

In the admin, click the **Settings** gear in the top bar. In the Settings sidebar, under **System**, select **Developer**.

To open the screen, your role needs at least **View only** for **Developer**, in the **Settings** card on the role's **Permissions** tab. See [Roles](/help/admin/settings/roles).

## What's on the screen

If your role has **Full access** to **Developer**, the header has a **Manage Webhooks** button. It opens the [Webhooks](/help/admin/settings/webhooks) screen.

### Resource cards

Under **Getting Started**, these cards link to resources. Click a card to open it.

- **Documentation**: opens the [Fluid documentation](/introduction) home page in a new tab.
- **API Reference**: opens the [API overview](/api/overview) in a new tab.
- **Support & FAQ**: opens [Getting help](/help/getting-help) in a new tab.
- **Webhooks**: opens the [Webhooks](/help/admin/settings/webhooks) screen, for sending event notifications to your external services.
- **API Tokens**: opens the [API Tokens](/help/admin/settings/tokens) screen, where you issue and revoke the tokens that authenticate your API calls.
- **Skills**: opens Fluid's agent skills for Claude Code, Cursor and other tools on GitHub, in a new tab. The card is marked **New**.
- **Master the CLI**: opens the [Fluid CLI guide](/themes/cli#installation) in a new tab.
- **Meet Mist**: opens the [Mist Apps](/help/admin/settings/mist-apps) screen, if your role has access to **Mist**. The card is marked **New**.

### Mist Desktop

Below the cards, the **Meet Mist Desktop** banner, marked **New** and **Beta**, lets you download the Mist Desktop app. Click anywhere on the banner to start the download.

- The button on the banner names the system the screen detected, for example **Download for Windows** or **Download for macOS (Apple Silicon)**.
- If the button reads **Download for macOS** or **Download for macOS (Apple Silicon)**, an **Intel Mac? Get the x64 build** link appears below the banner. If your Mac has an Intel processor, use that link. It opens the Mist Desktop releases page in a new tab, where you can download the x64 build.
- If the screen can't find a download for your system, it opens the Mist Desktop releases page instead.

### Developer tools

Under **Set Up Your Developer Tools**, two cards help you set up the tools Fluid recommends for building on Fluid.

- **Install the Fluid CLI**: shows commands that install the Fluid CLI and sign you in. The CLI lets you manage themes, portals, droplets and more from your terminal. **View the full CLI guide** opens the [Fluid CLI guide](/themes/cli#installation) in a new tab.
- **Connect the Fluid Docs MCP server**: shows how to connect Claude Code, Cursor or another client that supports the Model Context Protocol (MCP) to Fluid's documentation, so you can search the docs without leaving your editor. It has setup steps for **Claude Code**, **Cursor**, **VS Code (Copilot)** and **Claude Desktop**.

The docs MCP server is hosted and read-only, at `https://docs.fluid.app/mcp`. There's nothing to install, and you don't need an API token. It only searches published documentation. It can't read or change your company's data. To act on your store, use the Fluid API with a token from [API Tokens](/help/admin/settings/tokens).

### Fluid SDK

The **Fluid SDK** card has a script snippet that embeds the Fluid SDK in your website or app, with your company's subdomain already filled in. To copy it, click the copy icon at the top right of the snippet. **Fluid SDK Documentation** opens the [SDK overview](/sdk/overview).

Fluid-hosted storefronts already load the SDK, so add it only to sites Fluid doesn't host. For installation steps and configuration, see [Installation](/sdk/installation).

## Set up the Fluid CLI

The **Install the Fluid CLI** card shows commands to install the CLI and sign in. For full installation steps and the CLI's commands, see the [Fluid CLI guide](/themes/cli#installation).
