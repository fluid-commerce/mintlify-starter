Use this screen to set a default schedule time for media. When you schedule a media item to go live, or to stop showing, the date picker starts at this time instead of 12:00 PM.

## Where to find it

In the admin, click the **Settings** gear in the top bar. In the Settings sidebar, under **Company**, select **Media**.

<Note>
Your role needs these permissions, as named on the [Roles](/help/admin/settings/roles) screen:

- At least **View only** for **Media**, in the **Content & Website** card, to open this screen.
- **Full access** for **Company Settings**, in the **Settings** card, to change the default time. Without it, the screen shows **You have view-only access to these settings.**
</Note>

## What's on the screen

### Default schedule time

This card holds one company-wide time. It applies to every admin, and each admin's pickers start at that time of day in their own time zone.

- With no default, the card reads **No default. New times start at 12:00 PM.** and shows **Set a default time**.
- With a default, the card shows the time and **Clear default**.

The default only sets where the picker starts. A media item that already has a scheduled date and time keeps it, and you can still pick any time before you confirm.

## Set a default schedule time

<Steps>
  <Step title="Add a time">
    In the **Default schedule time** card, click **Set a default time**. The time field appears, set to 12:00 PM.
  </Step>
  <Step title="Pick the time">
    Change the time to the one your team uses most, for example 6:00 AM.
  </Step>
  <Step title="Save the change">
    Click **Save** at the top of the page. **Save** becomes available once you change the time. A confirmation message appears when the change is saved.
  </Step>
</Steps>

To go back to 12:00 PM, click **Clear default**, then click **Save**.

## Where the default time is used

On a media item's page, the **Status** card uses the default time when the item has no time stored:

- choosing **Scheduled** opens the picker for **Schedule Activation** at the default time;
- adding a deactivation date opens the picker for **Schedule Deactivation** at the default time.

See [Set the status](/help/admin/media#set-the-status).
