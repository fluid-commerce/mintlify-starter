Use the **Translate metafields** page to work on one translatable product field in one language across all your products. You see each product's original value next to its translation, so you can translate a whole field in one sitting.

<Note>
  This feature may not be available to your company yet. If it isn't on for your company, the page doesn't open.
</Note>

## Before you start

- Make the field translatable first. See [Make a field translatable](/help/admin/settings/metadata-definitions#make-a-field-translatable).
- Turn on at least one language besides your default language on the [Languages](/help/admin/settings/languages) screen. The default language holds the original values, so you can't translate into it. Without another language, the page says "Add a language besides your default one to translate this field."
- This page covers product fields only. Translate a variant's or an enrollment pack's fields on its own page. See [Translate variant metafields](/help/admin/products#translate-variant-metafields) and [Translate enrollment pack metafields](/help/admin/enrollments#translate-enrollment-pack-metafields).

## Permissions you need

- To open the page, your role needs at least **View only** for **Company Settings**. The page also reads your products, so your role needs to view them. If you lose access while the page is open, it says "You no longer have access to translate products."
- To save a translation, your role needs the **Products** permission that starts with **Edit product details, pricing, and images**. Without it, a row's **Save** shows "You don't have permission to save this translation."
- To use **AI-translate all missing**, your role needs that **Products** permission and the **Application Themes** permission that starts with **Customize and edit theme settings**.
- **Export CSV** needs the same access as viewing the products.

See [Roles](/help/admin/settings/roles) for how to change a role.

## Where to find it

In the admin, click the **Settings** gear in the top bar. In the Settings sidebar, under **Commerce**, select **Metadata Definitions**, then click **Product Metadata**. On a translatable field's row, click **Translate values**.

The page's title is the field's name, for example **How to use**. Its breadcrumb reads **Metadata** > **Product Metadata** > **Translate metafields**. If you open the page without a field, it asks you to choose one from the product metafield definitions.

## What's on the screen

At the top of the page:

- **Language**: the language you're translating into. It lists your active languages except the default one. Changing it loads that language's translations.
- **Refresh**: reads the latest values and translations again.
- **Export CSV**: downloads the field's translations in this language as a CSV file. See [Export to CSV](#export-to-csv).
- **AI-translate all missing**: has AI translate every product whose translation is missing. See [Translate the missing values with AI](#translate-the-missing-values-with-ai).

Below them, a table lists the products that have a value for the field, oldest first. It has these columns:

- **Product**: the product's title and its ID, for example **Wellness Kit** and #48213.
- **Original**: the value in your default language. You can't change it here.
- **Translation**: the value in the language you chose.
- **Status**: where the translation stands. See [What the statuses mean](#what-the-statuses-mean).

Each row has a **Save** button. **Previous** and **Next** below the table move between pages of products. A product that has no value for the field isn't listed, and neither is a deleted product. If no product has a value, the page says "No product has a value for this field yet."

## Translate a field

<Steps>
  <Step title="Choose a language">
    In **Language**, choose the language you want to translate into.
  </Step>
  <Step title="Write the translation">
    In a row's **Translation** column, enter the value. The input matches the field's type:

    - A single line text field and a **Url** field have one text box.
    - A multi line text field has a larger text box.
    - A rich text field shows a preview. Click **Edit** to open the editor, then **Done** when you finish.
    - A list field has one box for each item in the original, with the original item as the hint. A list translation needs the same number of items as the original.
  </Step>
  <Step title="Save the row">
    Click **Save** in the row. You see **Translation saved**. **Save** is grayed out until you change the value, except on a row marked **Outdated** or **Not showing**, which you can save as it is to confirm it. It stays grayed out while the value is blank.
  </Step>
</Steps>

Your unsaved edits stay when you move to another page of products or click **Refresh**. They are lost when you change the language or leave the page.

If a product's original changes while you're editing its row, the row says "The original changed since you started editing." and shows **Outdated**. What you save is stored as **Outdated**, because you wrote it for the earlier original.

Shoppers see a saved translation where your theme prints the field. Fluid refreshes your cached storefront pages a few minutes after a save, so a new translation can take about five minutes to show. See [Theme variables](/themes/theme-variables#translated-metafields).

## What the statuses mean

| Status | What it means |
| --- | --- |
| **Translated** | The translation matches the current original. |
| **Outdated** | The original changed after you translated it. Shoppers still see the translation. Read it again, change it if you need to, and click **Save** to confirm it against the new original. |
| **Missing** | There is no translation, or it's blank. Shoppers see the fallback instead. |
| **Not showing** | The translation can't be shown to shoppers because it has a different number of list items than the original. Fix the number of items and save. |

When a language has no usable translation, shoppers see the field's English translation if you have one, and otherwise the original value. See [What shoppers get](/storefront/metafields#what-shoppers-get) for the full rule.

## Translate the missing values with AI

Click **AI-translate all missing**. Fluid queues a background run and shows "AI translation is queued. Refresh in a few minutes to see the new values."

- The run translates only products whose status is **Missing**. It never replaces a translation that has text, even one marked **Outdated**.
- It skips products whose original is blank.
- It uses your company's AI spend. If the allowance runs out, the run stops, and the products it already translated keep their translations. See [AI Spend](/help/admin/settings/ai-spend).
- If a run for the same field and language is already going, you see "AI translation is already running for this field and language. Refresh in a few minutes to see the new values." Nothing new starts.

Click **Refresh** after a few minutes to see the new translations, then review them. Have someone who speaks the language check anything that matters, such as ingredient or safety text.

## Export to CSV

Click **Export CSV** to download a file named after the field and language, for example `custom-how_to_use-es.csv`. It has one row for every product the page would list, not only the current page. The columns are the product ID, title, original, translation and status. A list value shows one item per line.

Use the file to review translations or send them to a translator. This page has no CSV import.

## FAQ

<AccordionGroup>
  <Accordion title="Why isn't my product in the table?" id="product-not-listed">
    The table lists products that have a value for this field. Add a value on the product's **Metafields** card first. Deleted products aren't listed.
  </Accordion>
  <Accordion title="Why is Save grayed out?" id="save-grayed-out">
    You haven't changed the value, or the value is blank. A row marked **Outdated** or **Not showing** can be saved as it is, to confirm it.
  </Accordion>
  <Accordion title="Why did AI-translate all missing say I need permission?" id="ai-needs-permission">
    The run needs both the **Products** permission to edit product details and the **Application Themes** permission to customize theme settings. Ask an admin who manages roles to update your role. See [Roles](/help/admin/settings/roles).
  </Accordion>
  <Accordion title="Why don't I see Translate values?" id="no-translate-values">
    Translatable metafields may not be on for your company yet. The button also appears only on **Product Metadata**, and only for a field whose **Translatable** switch is on.
  </Accordion>
</AccordionGroup>
