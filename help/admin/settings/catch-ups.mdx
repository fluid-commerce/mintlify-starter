Catchups are follow-up suggestions for your affiliates. Use this screen to choose which types are on for your whole company.

## Where to find it

In the admin, click the **Settings** gear in the top bar. In the Settings sidebar, under **Company**, select **Catchups**.

## What's on the screen

The screen groups its switches into cards. For a new company, every switch starts off. The descriptions below mostly follow the screen's own text. For **Last Order Seven Days Ago** and **New Purchase**, they're more exact than the text on the screen.

### Orders & Subscriptions

| Switch | Description |
| --- | --- |
| **Cart Abandoned** | A contact abandons their cart with items left inside. |
| **Enrolled** | A contact creates a new enrollment. |
| **Multiple Orders But No Subscription** | A contact repeatedly orders a product without subscribing. |
| **Last Order Seven Days Ago** | A contact placed an order 7 days ago. Subscription orders don't count. |
| **Last Affiliate Order Ten Days Ago** | An affiliate's order was placed 10 days ago. |
| **Smart Link Share But No Order** | A SmartLink was sent 2 days ago but no order followed. |

### Activity

| Switch | Description |
| --- | --- |
| **Recent Web Activity** | A contact views a shared page (daily summary). |
| **Video Viewed** | A contact starts a video but doesn't finish watching. |
| **New Product** | A new product is added and a contact has not viewed or purchased it. |
| **New Media Added** | You add new media that should be shared with a contact. |
| **New Training Material** | New training material is added. |
| **New Trending Media** | Media is tagged as trending and is ready to be shared with a contact. |
| **New Reaction on Media** | A contact reacts to shared media. |
| **Review on Product** | A contact writes a review that can be shared. |

### Messages & Tasks

| Switch | Description |
| --- | --- |
| **Overdue Task** | An affiliate's task is overdue. |
| **Unresolved WebChat** | A web chat message to an affiliate is unanswered. |
| **Unresolved Popup Chat** | A message from the pop-up feature is unresolved. |
| **Unresolved Media Comment** | A contact comments on media an affiliate shared and the comment remains unresolved. |
| **Unread Message** | Affiliates have unread company or contact messages (daily summary). |
| **Upcoming Event** | One of your company's events starts within the next 2 days. |

### Groups

| Switch | Description |
| --- | --- |
| **No Group Assigned** | A contact has not been assigned to any group. |
| **Group Update Threshold Reached** | A contact's group hasn't been updated in over 60 days. |
| **New Leader on LeaderBoard** | A new affiliate takes the top spot on the leaderboard. |

### Other

| Switch | Description |
| --- | --- |
| **New Purchase** | A contact places their first order. The Catchup goes to the affiliate the order is credited to. |
| **New Purchase of Lead** | A new lead is purchased. |

### Custom

This card has no switches. Your developers can create custom Catchups. The card's **Custom Catchups Documentation** button opens the [Fluid API overview](/api/overview), the general starting point for developers.

## Turn a Catchup on or off

<Steps>
  <Step title="Find the Catchup">
    Catchups are grouped into cards by topic, such as **Orders & Subscriptions**, **Activity** and **Groups**. Find the card that holds the one you want.
  </Step>
  <Step title="Turn the switch on or off">
    Click the switch next to the Catchup's name. The change saves right away, and you see **Catch-Up setting updated successfully.** This screen has no save button.
  </Step>
</Steps>

If a change fails, you see **Failed to update catch-up setting** and the reason, and the switch returns to its saved position.

## FAQ

<AccordionGroup>
  <Accordion title="Can I set Catchups by role, by user, or by time of day?" id="catchup-options">
    No. These switches apply to your whole company. Each Catchup type has one on/off switch, with no role, user, or timing options.
  </Accordion>
  <Accordion title="Why are the switches grayed out?" id="switches-grayed-out">
    Your role has **View only** access to **CatchUp**, so the switches and the **Custom Catchups Documentation** button are grayed out. Ask an admin who manages roles to set the **CatchUp** area to **Full access** on your role's **Permissions** tab. Use the area's own menu, in the **Settings** card, not the card's menu. See [Roles](/help/admin/settings/roles).
  </Accordion>
  <Accordion title="Why can't I see Catchups in the Settings sidebar?" id="catchups-missing">
    The **Catchups** item appears only if your role has the **CatchUp** area, in the **Settings** card, set to at least **View only**. Ask an admin who manages roles to update your role. See [Roles](/help/admin/settings/roles).
  </Accordion>
</AccordionGroup>
