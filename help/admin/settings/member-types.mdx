Use the Member Types screen to manage your company's member types. For each type, you set the pricing tier its members price at and whether they can act as a rep.

## Where to find it

In the admin, click the **Settings** gear in the top bar. In the Settings sidebar, under **Commerce**, select **Member Types**.

To open the screen, your role needs at least **View only** for **Member Types**, in the **Other** card on the role's **Permissions** tab. To create, edit or archive member types, your role needs **Full access** for **Member Types**.

## What's on the screen

The **Create Member Type** button is in the page header.

The table lists one row per member type, including archived types. System member types come first. Within each group, types are sorted by name.

- **Name**: the member type's name. A **System** badge marks a system member type, and an **Archived** badge marks an archived one.
- **Slug**: the type's slug, set from its name when the type is created.
- **Pricing tier**: the pricing tier that members of this type price at. **Company default** means the type has no tier set, so it uses your company's default pricing tier.
- **Can act as rep**: **Yes** or **No**.

Each row has an **Edit** button, and each row that isn't a system member type has an **Archive** button. **Archive** is disabled for a type that's already archived.

If your company has no member types, you see **No member types found**. If the list can't load, you see an error such as **Couldn't load member types.** and a **Try again** button.

### Member type panel fields

**Create Member Type** and **Edit** open a side panel titled **Create Member Type** or **Edit Member Type**. In order, it has:

- **Name** (required). A new member type can't reuse the name of an existing one, even with different capitalization or if that type is archived.
- **Slug**: shown read-only when you edit a type. When you create a type, the panel tells you the slug is generated automatically from the name. Renaming a type doesn't change its slug.
- **Pricing tier**: the tier that members of this type price at. Choose **Company default** or one of the standard pricing tiers. As the panel notes, only system price types can be assigned today, so custom price types aren't listed. **Company default** leaves the tier unset, so the type uses your company's default pricing tier. The option shows that tier's name, for example **Company default (Retail)**. A new type starts on **Company default**.
- **Can act as rep**: turn this on to let members of this type act as a rep. It's off for a new type.

The panel has **Cancel** and **Save** buttons. If you leave **Name** empty, you see **Name is required** when you click **Save**.

## Create a member type

<Steps>
  <Step title="Open the panel">
    Click **Create Member Type**.
  </Step>
  <Step title="Enter the details">
    Enter a **Name**, for example `Ambassador`. Choose a **Pricing tier**, or leave it on **Company default**. To let members of this type act as a rep, turn on **Can act as rep**.
  </Step>
  <Step title="Save">
    Click **Save**. You see **Member type created**, and the new type appears in the table.
  </Step>
</Steps>

## Edit a member type

You can also edit system member types, for example to change their pricing tier.

<Steps>
  <Step title="Open the panel">
    In the member type's row, click **Edit**. The **Edit Member Type** panel opens with the current details.
  </Step>
  <Step title="Change the details">
    Change the **Name**, the **Pricing tier** or the **Can act as rep** setting. The slug stays the same.
  </Step>
  <Step title="Save">
    Click **Save**. You see **Member type updated**.
  </Step>
</Steps>

## Archive a member type

Archive a member type you no longer use. Members who already have the type keep it. The type stays in the table with an **Archived** badge. You can't archive a system member type.

<Warning>
  You can't unarchive a member type from this screen. Archive a type only when you're sure you no longer need it.
</Warning>

<Steps>
  <Step title="Choose Archive">
    In the member type's row, click **Archive**.
  </Step>
  <Step title="Confirm">
    The **Archive member type** dialog asks you to confirm. Click **Archive**. You see **Member type archived**.
  </Step>
</Steps>

## Frequently asked questions

<AccordionGroup>
  <Accordion title="What's the difference between Company default and choosing the default tier itself?" id="company-default-vs-retail">
    Members of the type price the same either way. **Company default** leaves the type without a tier, and the **Pricing tier** column shows **Company default**. Choosing the default tier itself, such as Retail, sets it on the type, and the column shows the tier's name.
  </Accordion>
  <Accordion title="Why can't I choose a pricing tier or click Save?" id="pricing-tiers-unavailable">
    The panel loads your company's pricing tiers when it opens. Until they load, the **Pricing tier** list shows **Loading pricing tiers...** and **Save** is disabled. If they can't load, you see **Pricing tiers could not be loaded.** Click **Try again**.
  </Accordion>
  <Accordion title="What happens if a save fails?" id="save-failed">
    You see an error with the reason, for example **A member type named "Ambassador" already exists**. The panel stays open with your entries, so you can fix them and click **Save** again.
  </Accordion>
  <Accordion title="Why can't I see Member Types in the Settings sidebar?" id="member-types-missing-from-settings">
    The **Member Types** item appears only if your role can view member types. Ask an admin who manages roles to edit your role's permissions: open the **Other** card, then set **Member Types** to **View only** or **Full access**. See [Roles](/help/admin/settings/roles).
  </Accordion>
  <Accordion title="Why can't I create, edit or archive member types?" id="member-type-actions-missing">
    The **Create Member Type**, **Edit** and **Archive** buttons appear only if your role has **Full access** for **Member Types**. With **View only**, you can see the table but not change it. Ask an admin who manages roles to open the **Other** card and set **Member Types** to **Full access**. See [Roles](/help/admin/settings/roles).
  </Accordion>
</AccordionGroup>
