Use the **Shop Tabs** screen to build the Shop screen of your company's mobile app. Shop pages work like home pages: each has tabs across the top, widgets on each tab and access rules, and they open in the same editor. This page covers what's different. For the editor, see [Home Tabs](/help/admin/mobile/home). For how reps use the app, see [Mobile app](/help/mobile).

## Where to find it

In the admin sidebar, under **Mobile App**, select **Shop Tabs**.

<Note>
  To open this screen and the page editor, your role needs **View only** or **Full access** for **Mobile Pages**. With **View only**, pages open in the editor without a **Save** button, and the list has no actions menu. To create, edit, duplicate, set the default or delete pages, it needs **Full access**. On the [Roles](/help/admin/settings/roles) screen, **Mobile Pages** is in the **Content & Website** card. Open the card and set access from the **Mobile Pages** area's menu, not the card's.
</Note>

## What's on the screen

**New Page** and **Advanced Search** are above the list of your company's shop pages. The list always includes your default shop page, marked **Default**. Members who match no other active shop page see it.

The list works like the one on Home Tabs: the **All**, **Active** and **Inactive** tabs, search, sorting by **Name** or **Status**, the same columns and the same actions menu. See [Pages list](/help/admin/mobile/home#pages-list). **Not in navigation for:** in the **Member Type** column means a navigation hides the Shop screen from the members it names.

**Advanced Search** shows which shop page a member sees. It works as on [Home Tabs](/help/admin/mobile/home#advanced-search).

Tabs, access rules, publishing and the default page work as on Home Tabs, among shop pages. See [The page editor](/help/admin/mobile/home#the-page-editor).

### Widgets

The widget drawer on a shop page offers two product widgets, plus some of the widgets from home pages.

| Widget | What it shows |
| -- | -- |
| **Shop Unordered List** | A row of product cards, under a title |
| **Product Shop List** | Product cards in a two-column grid, under a title |

Both show only **Powered By** at first. Choose **Custom** to pick the items yourself, or a listed section for Fluid to fill the widget. For a section, also choose the **Number of Items to Display**. **Title**, the colors and the items then appear.

The drawer also offers **Carousel**, **Video**, **Spacer**, **Text**, **Alert**, **Ordered List**, **Nested Unordered List** and **Image**. They work as on home pages. See [Widgets](/help/admin/mobile/home#widgets). Your company's own widgets aren't offered on shop pages.

## Tasks

### Create a shop page

<Steps>
  <Step title="Start a new page">
    Click **New Page**. Fluid creates an inactive page named after you, such as **Alex's Page #44**, and opens it in the editor. It has one main tab, **Shop**.
  </Step>
  <Step title="Name it and choose who sees it">
    In **Settings**, change the **Page Name** and add access rules.
  </Step>
  <Step title="Add your products">
    Add a **Shop Unordered List** or **Product Shop List** widget, and any other tabs and widgets you need.
  </Step>
  <Step title="Publish and save">
    Turn on **Publish** when the page is ready for members, then click **Save**.
  </Step>
</Steps>

The new page stays in the list even if you close the editor without saving.

### Duplicate, set the default or delete a shop page

Use the page's actions menu in the list. These work as on Home Tabs; see [Duplicate, set the default or delete a page](/help/admin/mobile/home#duplicate-set-the-default-or-delete-a-page).
