Use the **Share Tabs** screen to build the Share screen of your company's mobile app. Share pages work like home pages: each has tabs across the top, widgets on each tab and access rules, and they open in the same editor. This page covers what's different. For the editor, see [Home Tabs](/help/admin/mobile/home). For how reps use the app, see [Mobile app](/help/mobile).

## Where to find it

In the admin sidebar, under **Mobile App**, select **Share Tabs**.

<Note>
  To open this screen and the page editor, your role needs **View only** or **Full access** for both **Share Pages** and **Mobile Pages**. With **View only**, pages open in the editor without a **Save** button, and the list has no actions menu. To create, edit, duplicate, set the default or delete share pages, it needs **Full access** for both. On the [Roles](/help/admin/settings/roles) screen, **Share Pages** is in the **People** card and **Mobile Pages** is in the **Content & Website** card. Open each card and set access from the area's menu, not the card's.
</Note>

## What's on the screen

**New Page** is above the list of your company's share pages. The list always includes your default share page, marked **Default**. Members who match no other active share page see it.

The list works like the one on Home Tabs: the **All**, **Active** and **Inactive** tabs, search, sorting by **Name** or **Status**, the same columns and the same actions menu. See [Pages list](/help/admin/mobile/home#pages-list). **Not in navigation for:** in the **Member Type** column means a navigation hides the Share screen from the members it names.

Access rules, publishing and the default page work as on Home Tabs, among share pages. See [Settings and access rules](/help/admin/mobile/home#settings-and-access-rules).

### System tabs

Share pages have system tabs, one each for uploads, playlists, products, enrollments, media and pages. Each opens a screen built into the app, so it has no widgets. A grid icon marks them in the **Tabs** sidebar.

- A new share page starts with all six under **Main Tabs**, named **Uploads**, **Playlists**, **Products**, **Enrollments**, **Media** and **Pages**. A page can have up to eight main tabs, so you can add two more, or move system tabs to **Not Linked** to make room.
- You can rename system tabs and drag them between **Main Tabs** and **Not Linked**, but you can't delete them.
- When you select a system tab, the preview shows a placeholder card instead of the screen, and **Settings** stays open.

Widget tabs and embed tabs work as on home pages. See [Tabs](/help/admin/mobile/home#tabs).

### Media creation

Share pages have one more setting. In **Settings**, under **Media creation**, the **Allow media creation** switch lets app users create uploads and playlists from this share page in the mobile app. It's on for a new share page. Click **Save** to apply a change.

### Widgets

The widget drawer on a share page offers these widgets, and your company's own widgets for share pages, if it has any, under **My Widgets**:

- **MySite**, **Unordered List**, **Ordered List**, **Video**, **Carousel**, **Spacer**, **Image**, **Text**, **Nested Unordered List**, **Quick Links** and **Subscriptions and Orders**. They work as on home pages. See [Widgets](/help/admin/mobile/home#widgets).
- **Quick Share**: one item to share, with a QR code. Choose the item under **Share Content**, from your enrollments, products, media, pages or playlists. You can also set its **Title**, **Text Color**, **Background** and **Overlay intensity**.
- **Quick Share Links**: links reps can share. Under **Links**, each link goes to a page of your website, such as a collection or post, to a web address, or to a shareable item. **Widget Title** sets the heading.

## Tasks

### Create a share page

<Steps>
  <Step title="Start a new page">
    Click **New Page**. Fluid creates an inactive page named after you, such as **Alex's Page #43**, with the six system tabs, and opens it in the editor.
  </Step>
  <Step title="Name it and choose who sees it">
    In **Settings**, change the **Page Name**, add access rules, and set **Allow media creation**.
  </Step>
  <Step title="Add your content">
    Add tabs and widgets, and arrange the system tabs.
  </Step>
  <Step title="Publish and save">
    Turn on **Publish** when the page is ready for members, then click **Save**.
  </Step>
</Steps>

The new page stays in the list even if you close the editor without saving.

### Duplicate, set the default or delete a share page

Use the page's actions menu in the list. These work as on Home Tabs; see [Duplicate, set the default or delete a page](/help/admin/mobile/home#duplicate-set-the-default-or-delete-a-page). A copy keeps the system tabs' names, order and sections.
